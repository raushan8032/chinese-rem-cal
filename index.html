Cryptography: RSA & CRT

The Chinese Remainder Theorem is fundamentally important in modern cryptography, particularly in the RSA algorithm.

RSA Decryption Optimization

Instead of computing m = cd mod (p*q) directly (which involves very large numbers), we can use CRT to solve it faster:

  1. Compute m1 = cd mod (p-1) mod p
  2. Compute m2 = cd mod (q-1) mod q
  3. Combine m1 and m2 using CRT to find m mod (p*q)

This reduces decryption time by roughly 75% on average!
